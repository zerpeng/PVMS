## 1. 项目背景与目标

### 1.1 背景分析
摄影爱好者在长期的创作过程中，通常会积累 TB 甚至 PB 级的照片和视频。目前市场上的管理方案存在以下痛点：
- **云端隐私忧虑**：公有云盘存在隐私泄露风险及昂贵的持续订阅费。
- **整理成本极高**：纯人工打标、分类极其耗时。
- **工具链破碎**：查看、管理、转码、简单剪辑通常需要切换 3-4 个软件。
- **性能瓶颈**：当单文件夹图片超过万张时，大多数系统会出现明显的加载卡顿。

### 1.2 项目目标
PVMS 旨在提供一个完全运行在本地、具备 AI 智能、支持专业元数据解析、并能进行媒体二次加工的综合管理平台。

## 2. 用户角色与权限管理 (RBAC)

系统采用严格的角色访问控制，确保在家庭或工作室环境下的数据安全与隐私隔离。

### 2.1 角色定义
- **管理员 (Admin)**：
    - 拥有系统的绝对控制权。
    - 负责添加、删除本地监控目录。
    - 管理所有用户账号及权限审批。
    - 负责 AI 助手的高级配置（模型更新、参数微调）。
- **普通用户 (Regular User)**：
    - 可查看并管理自己被授权的媒体库。
    - 支持自定义标签、创建相册。
    - 拥有完整的媒体加工（转码、合成）权限。
    - 不具备系统底层设置及 AI 核心管理权限。
- **访客 (Visitor)**：
    - 初始无任何查看权限。
    - 需通过系统发送访问申请。
    - 管理员审批通过后，仅能在指定有效期内查看特定的“授权相册”。

### 2.2 权限矩阵
| 功能模块 | 管理员 | 普通用户 | 访客 |
| :--- | :---: | :---: | :---: |
| 系统目录配置 | √ | × | × |
| 基础媒体浏览 | √ | √ | 仅限授权内容 |
| 自定义标签/相册 | √ | √ | × |
| 视频转码/GIF/合成 | √ | √ | × |
| AI 助手高级管理 | √ | × | × |
| 用户审批与授权 | √ | × | × |

## 3. 功能模块详细说明

### 3.1 智能索引与扫描模块 (Ingestion System)
这是系统的“感知神经”，负责将磁盘物理文件转化为结构化数据。

- **多路径监控**：支持添加本地硬盘、NAS 挂载路径、移动硬盘。
- **扫描模式**：
    - **全量扫描**：对新路径进行地毯式扫描，建立指纹库。
    - **增量监控**：基于文件系统 Hook，实时发现新素材。
    - **离线索引**：即便移动硬盘已拔出，系统仍保留其缩略图和元数据，并标记为“离线”。
- **文件指纹**：计算文件 Hash，自动识别并标记重复素材，节省空间。

### 3.2 专业元数据中心 (Metadata Center)
摄影师需要精准掌控每一项拍摄参数。

- **EXIF 解析**：拍摄时间（精确到秒）、相机型号、镜头、焦距、光圈、快门、ISO、白平衡、曝光补偿。
- **地理信息 (GPS)**：解析经纬度，并自动关联地理位置词库（如：上海市·武康路）。
- **视频属性**：编码格式（H.264/H.265/ProRes）、帧率、码率、HDR 标准。

### 3.3 组织与标签系统 (Organization System)
解决“海量素材如何归类”的问题。

- **层级标签体系**：支持用户自定义父子标签。
    - 示例：`人物 -> 家人 -> 孩子`；`植物 -> 花卉 -> 郁金香`。
- **内置维度**：系统预设常见标签维度：人物、地点、时间、食物、风景等。
- **相册管理**：
    - **普通相册**：手动整理。
    - **智能相册**：基于过滤条件动态生成（如：所有“西藏”+“五星好评”的照片）。
- **资产移除 (逻辑删除)**：支持从系统中移除指定的照片或视频。移除操作仅为数据库层面的逻辑删除（标记删除），不会删除本地磁盘上的原始文件，确保用户数据安全。

### 3.4 交互与浏览体验 (UX & Gallery)
- **高性能瀑布流**：利用虚拟列表技术，支持百万级素材流畅滚动。
- **动态预览**：视频缩略图悬停即自动播放精彩片段；图片悬停显示大图预览。
- **专业详情视图**：侧边栏展示直方图及详细 EXIF 数据。

### 3.5 媒体加工工厂 (Media Factory)
赋予摄影师快速处理与二次创作的能力。

- **视频转码引擎**：支持 MOV, AVI, MKV 向标准 MP4 格式转换，提供多种码率预设。
- **视频转 GIF**：支持截取视频任意片段，自定义分辨率与帧率导出。
- **照片合成视频 (Slideshow)**：用户选取一组照片，系统自动添加转场效果与背景音乐，一键导出短视频。

### 3.6 搜索与筛选系统 (Discovery System)
- **多条件筛选**：支持按日期范围、星级、相机型号、焦距段等进行精细过滤。
- **组合搜索**：支持“标签 + 关键字”的复合查询。

## 4. 阶段性路线图 (Roadmap)

考虑到系统复杂性，开发将分为三个大版本逐步迭代。

### 阶段一：V1.0 核心基础版 (Current Focus)
**目标：建立稳固的资产管理与浏览基础。**
- **核心功能**：目录监控、元数据解析、高性能瀑布流展示。
- **基本组织**：自定义标签、手动创建相册。
- **搜索筛选**：基于文件信息和标签的基础搜索。
- **权限管理**：实现管理员与普通用户的权限隔离。

### 阶段二：V2.0 创作增强版
**目标：引入媒体加工工具与访客协作。**
- **媒体工厂**：上线视频转码、GIF 导出、相册合成视频功能。
- **访客系统**：实现“访问申请-审批-限时查看”完整闭环。
- **性能加速**：利用 GPU 进行大规模缩略图渲染。

### 阶段三：V3.0 AI 智能管理版
**目标：全面引入本地 AI，解放双手。**
- **智能标签**：自动识别人脸、物体、场景（如：自动标记“花卉”、“猫”）。
- **AI 助手 (Copilot)**：
    - **自然语言搜索**：支持搜“去年春天拍的郁金香”。
    - **资产清理建议**：AI 自动识别模糊、重复、过曝的废片。
- **AI 高级管理**：管理员专属控制台，用于调整 AI 识别权重。

## 5. 技术约束与非功能需求

- **隐私保护**：所有 AI 运算及数据处理必须在本地执行，严禁私自外传数据。
- **兼容性**：
    - 操作系统：Windows 10/11, macOS, Linux (支持主流 NAS 系统)。
    - 图片格式：JPG, PNG, TIFF, HEIC, 及主流 RAW (DNG, ARW, CR3, NEF)。
- **性能标准**：
    - 首次扫描 10,000 张图片时间不应超过 5 分钟（含缩略图生成）。
    - 搜索结果响应时间应在 500ms 以内。
